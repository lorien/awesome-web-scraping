# Site-Specific Scrapers

Scrapers, crawlers and downloaders built for one specific website or a small
named set of websites, regardless of the implementation language.

## Contents

* [Video Platforms](#video-platforms)
* [Other Sites](#other-sites)

## Video Platforms

* [you-get](https://github.com/soimort/you-get) - (Python) YouTube/Youku/Niconico video downloader.
* [yt-dlp](https://github.com/yt-dlp/yt-dlp) - (Python) Feature-rich command-line audio/video downloader, fork of youtube-dl.
* [ytscrape](https://github.com/vsmutok/ytscrape) - (Python) Fast, lightweight, pure-HTTP library for scraping YouTube search, video & channel metadata, comments, and transcripts (sync & async).
* [Youtube-Downloader](https://github.com/jeckman/YouTube-Downloader) - (PHP) Script for downloading videos from youtube; also parsing youtube feed into RSS enclosures for podcatchers
* [ytdl-core](https://github.com/distubejs/ytdl-core) - (JavaScript) DisTube fork of ytdl-core: YouTube video info and downloads for Node.js.

## Other Sites

* [visura-api](https://github.com/zornade/visura-api) - (Python) REST API for automated Italian cadastral property record extraction from the SISTER portal, using Playwright for browser automation with SPID authentication.
* [amazon-orders](https://github.com/alexdlaird/amazon-orders) - (Python) A library (and CLI) for Amazon order history; line items, prices, and receipts.
* [google-maps-scraper-kit](https://github.com/Mahanaicoach/google-maps-scraper-kit) - (Python) Google Maps business scraper with email and social profile extraction to CSV, no API key.
* [Wayback-Archive](https://github.com/GeiserX/Wayback-Archive) - (Python) Download a whole website from the Wayback Machine and rewrite its links for offline viewing
* [tme-s](https://github.com/axmaier/tme-s) - (Python) Read public Telegram channels from the t.me/s/ web preview as JSON lines, without an API key, phone number or account
* [gmapsscraper](https://github.com/gmapsscraper/gmapsscraper) - (JavaScript) Free open-source Chrome/Edge extension to extract Google Maps and Bing Maps business listings to CSV without an API key.
